Code Integration

Monetize any MCP tool in 1 line

Wrap your Python FastMCP or Node.js tools with our decorator. No payment logic to write.

🐍 Python FastMCP Server

Protect tool execution for $0.01 per call. The SDK handles HTTP 402 challenges automatically.

# pip install aipp
from mcp.server.fastmcp import FastMCP
from aipp import protect_agent

mcp = FastMCP("My Monetized MCP Server")

# Monetize tool execution for $0.01
@mcp.tool()
@protect_agent(price=0.01)
def search_database(query: str) -> str:
    return f"Results for: {query}"
