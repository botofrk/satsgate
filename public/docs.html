Architecture Overview

aipp operates as an open-source, non-custodial smart price tag standard and payment challenge gateway. Rather than acting as an intermediary or holding user balances, aipp generates cryptographic payment requests settled autonomously between the buyer and the creator's wallet node.

AI M2M PROTOCOL · PYTHON / LANGCHAIN

Autonomous AI Agents & LangChain Tools

Enable autonomous LLM agents (LangChain, CrewAI, LlamaIndex, Claude MCP) to execute machine-to-machine micro-payments with Bitcoin Lightning L402 and cryptographic preimages.

Key Features:

  • Zero-Human Micro-Payments: AI agents can pay $0.005 (8 sats) per API inference or database query autonomously.
  • EU AI Act Article 26 Compliance: Every settlement returns a verifiable cryptographic receipt via client.get_receipt(payment_hash).
# Python: pip install aipp-sdk
from aipp import Aipp

client = Aipp(api_key="aipp_merch_YOUR_KEY")

# 1. Issue an L402 payment challenge for an AI tool
charge = client.create_charge(amount_usd=0.05, protocol="L402", memo="AI Query")
print("Invoice for Agent:", charge.payment_request)

# 2. Verify settlement & get EU AI Act Art. 26 Receipt
receipt = client.get_receipt(charge.payment_hash)
if receipt.get("status") == "settled":
    print("Settlement Proof Preimage:", receipt.get("preimage"))
CREATOR MONETIZATION · NOTION / EMBEDS

Monetizing Notion Templates & Pages in 3 Seconds

Sell Notion templates, productivity dashboards, research notes, or client portals without Gumroad's 10% fee or 2-week payout delays.

How to Monetize in 3 Steps:

  1. Get Your Duplicate Link: In your Notion page, click Share ➔ Publish ➔ Allow duplicate as template and copy the public link.
  2. Mint an AIPP Smart Tag: On aipp.dev, set your price (e.g. $1.00 / 1,500 sats), your Lightning/Base wallet, and paste your Notion duplicate link as the redirect target.
  3. Embed or Share: Paste your checkout URL directly in Notion using the /embed https://aipp.dev/embed/p_... command, or share it on Twitter/Reddit.
🏷️ Gumroad vs AIPP: Gumroad charges 10% + 30¢ and holds payouts for 14 days. AIPP charges 1% flat with zero holding time — payments land directly in your Phoenix or Base wallet upon settlement!

Monetizing AI Models & Gradio Spaces

# Python Gradio Example (pip install aipp-sdk)
from aipp import Aipp

client = Aipp(api_key="aipp_merch_YOUR_KEY")

def generate_image(prompt, preimage=None):

    receipt = client.get_receipt(preimage)

CLIENT UTILITY · EXTENSION

1-Click Chrome Extension

The AIPP Extension is an open-source browser companion that enables non-custodial content monetization across any web environment in under 3 seconds.

Two Core Operating Modes:

  • Mint Tag Mode: Activates a visual DOM element picker on your active tab. Click any text, image, or container to lock it and automatically generate the L402 paywall HTML snippet.
  • Quick Link Mode: Packages private links (PDF downloads, Calendly bookings, Google Drive files) into a hosted checkout link (https://aipp.dev/pay/p_...) with zero server setup.
POST /merchant/links/create

Create Smart Price Tag

Programmatically generate a hosted, shareable checkout URL for any digital product or asset.

curl -X POST https://aipp.dev/merchant/links/create \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: aipp_devtest" \
  -d '{
    "title": "Autonomous Agent Workflow Pack",
    "amount_usd": 0.25,
    "redirect_url": "https://example.com/download"
  }'
POST /invoice/create

Mint Dual-Rail Invoice Challenge

Generate a combined Lightning Invoice (L402) and Base USDC payment challenge (x402) on demand.

curl -X POST https://aipp.dev/invoice/create \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: aipp_devtest" \
  -d '{
    "amount_usd": 0.25,
    "protocol": "dual"
  }'
GET /invoice/status/:hash

Verify Settlement Status

Real-time endpoint called to verify whether a payment hash or EVM signature has achieved network confirmation.
