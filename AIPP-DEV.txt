Build a Lightning L402 payment gateway API called AIPP.

Stack: Node.js + Express + TypeScript. Single file entry point (index.ts).

Core flow:

1. POST /v1/topup
   - Accepts { amount_sats }
   - Creates Lightning invoice via LNBits API
   - Returns { invoice, payment_request, payment_hash }

2. GET /v1/confirm/:payment_hash
   - Polls LNBits to check if invoice is paid
   - If paid → generates API key (prefix: aipp_), stores in memory (Map)
   - Returns { api_key, balance_sats }

3. POST /v1/chat/completions (OpenAI-compatible)
   - Header: Authorization: Bearer aipp_xxxx
   - Validates api_key exists and has balance
   - LIMIT CHECK: max $100 USD per key per day, max $10 per single request
   - If limit exceeded → return 429 { error: "Daily limit reached ($100). Resets at midnight UTC." }
   - Deducts flat fee per request (5 sats default)
   - Proxies request to real OpenAI API
   - Returns OpenAI response as-is

4. GET /v1/balance
   - Header: Authorization: Bearer aipp_xxxx
   - Returns { balance_sats, daily_spent_usd, daily_limit_usd: 100, requests_made }

5. GET /v1/health
   - Returns { status: "ok", timestamp }

Rate limiting & safety middleware (apply to all routes):
- Daily spend tracker per API key:
    const dailySpend = new Map()
    interface SpendRecord { date: string; usd: number; requests: number }
    function checkLimit(apiKey, costUsd):
      - get today = new Date().toDateString()
      - if record.date !== today → reset { date: today, usd: 0, requests: 0 }
      - if record.usd + costUsd > 100 → throw 429
      - if costUsd > 10 → throw 400 "Single request exceeds $10 limit"
      - update record
- Per-IP rate limit: max 10 requests/minute (use express-rate-limit)
- Minimum topup: 100 sats

In-memory storage (Map) — no database yet:
- keys: Map<string, { balance_sats: number, created_at: Date }>
- dailySpend: Map<string, SpendRecord>
- payments: Map<string, { amount_sats: number, paid: boolean }>
