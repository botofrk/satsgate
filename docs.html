AIPP Documentation

A flat 1% fee. Non-custodial routing. Built for humans and machines.

Quick start

  1. Go to aipp.dev, paste your Lightning address or BOLT12 offer.
  2. Receive an API key starting with aipp_merch_.
  3. Call the /invoice/create endpoint to mint an invoice.
  4. Your customer pays it — 99% is instantly available in your merchant balance.
  5. Call the /merchant/payout endpoint to withdraw to your Lightning address.

Official SDKs

The fastest way to integrate AIPP is using our official SDKs for Node.js and Python. They provide fully typed clients and zero-dependency designs.

🐍 Python

pip install aipp-sdk 
from aipp import Aipp

client = Aipp("aipp_merch_...")
charge = client.create_charge(500)
print(charge.payment_request)

🟢 Node.js

npm install aipp-node 
import { Aipp } from 'aipp-node';

const aipp = new Aipp({ apiKey: '...' });
const charge = await aipp.createCharge({
  amountSats: 500
});

Authentication

Send the API key as a header:

HTTP Header
X-Api-Key: aipp_merch_xxxxxxxxxxxxxxxxxx

Register Merchant

POST /merchant/register

Request
{
  "name": "My AI Agent",
  "lnurl_address": "satoshi@getalby.com",
  "payout_mode": "manual",
  "payout_threshold": 0
}

Create an invoice

POST /invoice/create

Request
{
  // You can provide amount_sats OR amount_usd
  "amount_sats": 2100,
  "amount_usd": 1.50,
  "memo": "1 article unlock"
}
→ 200 OK
{
  "payment_hash": "0a1b...",
  "payment_request": "lnbc21000n1p..."
}

Check invoice status

GET /invoice/status/:hash

→ 200 OK
{
  "status": "settled"
}

Withdraw Funds (Manual Payout)

POST /merchant/payout

If your payout mode is manual, you can trigger a withdrawal of your balance to your configured Lightning address.

Request (Empty Body)
{}
→ 200 OK
{
  "message": "Payout triggered successfully",
  "amount_sats": 15000
}

L402 micropayments

Any of your endpoints can require Lightning payment using L402. The flow:

  1. Client requests resource → server returns 402 with macaroon + invoice.
  2. Client pays invoice via any Lightning wallet.
  3. Client retries with header Authorization: L402 <macaroon>:<preimage_hex>.

Try it live on the L402 demo page.

Webhooks

When a charge is paid, AIPP automatically forwards 99% to your Lightning address and writes a transaction to your dashboard. You can configure a webhook URL for your backend to be notified instantly.
