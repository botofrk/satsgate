Developer Documentation

aipp.dev is a high-performance, non-custodial **Bitcoin Lightning split-payment gateway** built for online shops, digital services, and autonomous AI agents. By integrating our gateway, you can accept Lightning payments from customers and route payouts directly to your own wallet in real-time, paying only a flat **1% fee**.

💡 Pure Non-Custodial Flow
AIPP does not custody or hold your earnings. Payments are programmatically split on-the-fly and routed to your destination wallet (via Lightning Address) in miliseconds.

1. Merchant Registration

To register your shop or service, send a POST request with your destination Lightning Address. You will instantly receive your Merchant API Key:

HTTP POST /merchant/register 
curl -X POST http://localhost:3000/merchant/register \
  -H "Content-Type: application/json" \
  -d '{
    "ln_address": "mehmet@phoenixwallet.me"
  }'

Response format:

JSON Response 
{
  "api_key": "aipp_merch_72a391fbce",
  "ln_address": "mehmet@phoenixwallet.me"
}

2. Create Invoice

To charge a customer, call the invoice creation endpoint. Invoices must be between **100 satoshis** and **100,000 satoshis**:

HTTP POST /invoice/create 
curl -X POST http://localhost:3000/invoice/create \
  -H "Content-Type: application/json" \
  -H "X-AIPP-Key: aipp_merch_72a391fbce" \
  -d '{
    "amount_sats": 500,
    "callback_url": "https://yourshop.com/webhook/aipp"
  }'

Response format:

JSON Response 
{
  "payment_request": "lnbc5u1p4y...",
  "payment_hash": "e93fca1029ab8..."
}

3. Webhook Callbacks

When the customer pays the Lightning invoice, AIPP automatically splits the payment, sends 99% of the amount to your Lightning Address, and fires a POST notification to your specified callback_url:

Webhook POST Payload 
{
  "payment_hash": "e93fca1029ab8...",
  "amount_sats": 500,
  "forwarded_amount_sats": 495,
  "status": "settled"
}

4. Polling Payout Status

You can also poll the status of any invoice from the frontend using the payment hash:

HTTP GET /confirm/:hash 
curl http://localhost:3000/confirm/e93fca1029ab8...

Response format:

JSON Response 
{
  "paid": true,
  "status": "settled"
}

Python Integration Example

Complete backend Python code to generate a payment request and handle callbacks:

Python 
import requests

aipp_key = "aipp_merch_72a391fbce"

def create_checkout_session(amount_sats, order_id):
    url = "http://localhost:3000/invoice/create"
    headers = {
        "X-AIPP-Key": aipp_key,
        "Content-Type": "application/json"
    }
    payload = {
        "amount_sats": amount_sats,
        "callback_url": f"https://myonlinebuttique.com/webhook?order={order_id}"
    }
    response = requests.post(url, json=payload, headers=headers)
    return response.json() # Returns {"payment_request": "lnbc...", "payment_hash": "..."}

Node.js Integration Example

Complete Node.js / Express snippet to generate invoices and poll payout status:

Node.js / Express 
const axios = require('axios');

async function getInvoice(sats) {
  const response = await axios.post('http://localhost:3000/invoice/create', {
    amount_sats: sats,
    callback_url: 'https://myshop.com/payout-webhook'
  }, {
    headers: { 'X-AIPP-Key': 'aipp_merch_72a391fbce' }
  });
  return response.data; // { payment_request, payment_hash }
}

async function checkStatus(hash) {
  const response = await axios.get(`http://localhost:3000/confirm/${hash}`);
  return response.data; // { paid: true, status: 'settled' }
}
